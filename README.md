# 3D Cozy Lofi Room

An immersive 3D WebGL room built with Three.js, featuring fixed eye-level camera perspective (*Granny*-style look-around), smooth magnification zoom, and seamless native background music playing *"Rakhlo Tum Chupa Ke"* by Arpit Bala.

## 🎮 Features
- **3D Cozy Atmosphere**: Warm amber desk lighting, rainy night city window view, custom coding terminals, vinyl player, bookshelves.
- **Granny-Style Look Around**: Fixed eye-level perspective; look around 360° with mouse / touchpad / touchscreen drag.
- **Smooth Zoom**: Zoom in/out to inspect room details using mouse scroll wheel, touchpad gesture, or pinch-to-zoom.
- **Embedded Audio**: Background playback of *"Rakhlo Tum Chupa Ke"*.
